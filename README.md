## 👨‍💻 About Me

I'm **Kirby Acoba**, a full-time **Computer Science** student at **Mapúa University** specializing in **Artificial Intelligence**.

Outside of my coursework, I enjoy building real-world projects that strengthen my technical skills and allow me to apply what I learn. I recently completed a freelance website for a cleaning service business in Canada, giving me valuable experience working with an actual client and delivering software for production use.

I started programming because I wanted to create solutions for everyday problems while building projects that inspire and challenge me. Every project is an opportunity to learn a new framework, improve my software design skills, and become a better developer.

I'm particularly interested in:

- 🤖 Artificial Intelligence
- 🌐 Full-Stack Development
- 💻 Software Engineering
- 🚀 Building applications that genuinely help people

My long-term goal is to become a **Software Engineer** and eventually specialize as an **AI Engineer** developing technology with meaningful impact.
